プライバシーポリシー

このページは、YouTube チャンネル「もとはる」（https://www.youtube.com/channel/UCSf34sSJwvM1HGrXyWIL3tg）の運営者が、自分のチャンネルの動画を作るために使う個人用ツール「生態系ショート制作ツール」（以下「本ツール」）での情報の扱いを説明するものです。本ツールは YouTube API サービスを利用しています。

集める情報

  • 運営者のチャンネルの動画に付いたコメントのうち、「#放流」の合言葉が付いたコメントの本文、投稿日時、コメントした人のチャンネル ID
  • 運営者自身の YouTube アカウントで動画を投稿するための許可（OAuth のトークン）

使い道

  • 「#放流」の後に書かれた名前を、シミュレーションの生き物の一族の名前として動画に表示します。
  • コメントした人のチャンネル ID は、名前の削除を依頼されたときに、その人の名前を探して消すためだけに使います。
  • 運営者が確認して採用した動画を、運営者のチャンネルに投稿します。

不適切な名前や、電話番号・メールアドレスらしき文字列を含む名前は使いません。

保存と共有

情報は運営者のコンピューターにだけ保存し、第三者に提供・販売しません。動画に表示された名前は、投稿した動画の中で公開されます。

削除の依頼

自分の名前を使ってほしくない、または消してほしいときは、運営者のチャンネルの動画にコメントでお知らせください。記録から名前を消し、その名前を使った動画を取り下げます。

Google・YouTube の規約

本ツールは YouTube API サービスを利用しています。YouTube の利用規約（https://www.youtube.com/t/terms）と Google のプライバシーポリシー（https://policies.google.com/privacy）も適用されます。Google のセキュリティ設定ページ（https://security.google.com/settings/security/permissions）から、本ツールへの許可をいつでも取り消せます。

連絡先

運営者のチャンネルの動画へのコメントでご連絡ください。
