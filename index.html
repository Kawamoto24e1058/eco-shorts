生態系ショート制作ツール

YouTube チャンネル「もとはる」（チャンネルを見る）の運営者が、自分のチャンネルのショート動画を作るために使う個人用ツールです。ほかの人は利用できません。

しくみ

  1. 海の生態系シミュレーション（CG）を運営者のコンピューターで動かします。
  2. 動画に「#放流 名前」とコメントすると、その名前の魚の一族がシミュレーションの海に放流されます。
  3. 一族の運命（繁栄・絶滅など）を縦型の短い動画にします。
  4. 運営者が 1本ずつ確認し、採用した動画だけを YouTube API で自分のチャンネルに予約投稿します。
